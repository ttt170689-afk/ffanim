# ZIP Viewer

Веб-просмотрщик ZIP с просмотром файлов, потоковой распаковкой, сохранением на сервер и публичными ссылками.

## Запуск локально

```bash
python3 server.py
```

Откройте `http://localhost:8000`.

## Деплой на Render

1. Загрузите эти файлы в GitHub-репозиторий: `index.html`, `server.py`, `render.yaml`.
2. На Render выберите **New → Web Service** и подключите репозиторий.
3. Укажите:
   - Runtime: **Python**
   - Build Command: оставить пустым
   - Start Command: `python3 server.py`
4. Нажмите **Deploy**.

Render сам передаст приложению порт через переменную `PORT`.

Важно: на бесплатном Render локальные загруженные архивы хранятся на временном диске и могут исчезнуть после перезапуска сервиса. Для постоянного хранения подключите persistent disk или внешнее хранилище (S3/R2/Supabase Storage).
